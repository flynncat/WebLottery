# 直播抽奖监控 · Chrome 扩展

在你**自己打开的 Chrome 直播页**里检测抽奖倒计时，出现后用系统通知提醒。不会启动浏览器，也不会自动点击抽奖。

这是独立于桌面版（`app.py`）的实现，两者互不影响。

## 和桌面版的区别

| | 桌面版 Playwright | 本扩展 |
| --- | --- | --- |
| 谁打开直播页 | 脚本启动 Chrome | 你自己打开 |
| 登录态 | `.chrome-profile` | 当前 Chrome 已有登录 |
| 自动化特征 | 有 | 基本没有 |
| 自动点抽奖 | 否 | 否 |

## 安装（开发者模式）

1. 打开 Chrome，地址栏进入 `chrome://extensions/`
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**
4. 选中本目录 `chrome-extension`

加载成功后，工具栏会出现「直播抽奖监控」图标。

## 使用

1. 用普通 Chrome 打开并登录直播页，例如 `https://qlive.woa.com/user/live?liveId=...`
2. 保持扩展开启（弹窗里的「启用监控」）
3. 倒计时出现后会弹出系统通知；点击通知回到该标签页
4. **请再手动点抽奖**

首次使用时，若 Chrome 询问通知权限，请允许。

## 检测依据

与桌面版相同：

| 状态 | 页面特征 |
| --- | --- |
| 未开始 / 已结束 | `.count-time` 文案为「查看结果」或「抽奖」 |
| 抽奖倒计时 | `.count-time` 内 `status="1"`，或可见时间为 `00:10` 这类格式 |

## 目录

```
chrome-extension/
├── manifest.json
├── content.js        # 页面内检测倒计时
├── background.js     # 系统通知、角标
├── popup.html        # 开关与状态
├── popup.css
├── popup.js
└── icons/
```

## 注意

- 只匹配 `qlive.woa.com` 直播页
- 扩展重载或刚打开页面时，若弹窗显示「正在等待页面脚本」，刷新直播页即可
- 直播页 DOM 若改版，需要同步改 `content.js` 里的选择器
